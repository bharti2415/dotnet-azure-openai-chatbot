
# .NET + Azure OpenAI Chatbot 🤖

A simple **ASP.NET Core 8 Web API** that integrates with **Azure OpenAI** to provide chatbot responses.

---

## 🚀 Features
- .NET 8 Web API
- Connects to Azure OpenAI (`gpt-35-turbo` or `gpt-4`)
- REST endpoint for chatbot interaction
